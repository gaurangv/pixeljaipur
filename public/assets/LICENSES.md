# Asset licences

Every asset gets one line: file, source URL, author, licence.

## Map data

- `data/raw/*.osm.json`, `data/build/*`: © OpenStreetMap contributors, available under the Open Database Licence (ODbL), https://www.openstreetmap.org/copyright
- `data/raw/*.overture.geojson`, buildings with `source: overture:*` in `data/build/*`: Overture Maps Foundation buildings theme, ODbL, https://docs.overturemaps.org/attribution/. Includes Google Open Buildings (CC BY 4.0 / ODbL) and Microsoft Global ML Building Footprints (ODbL).
- Buildings with `source: generated` are procedurally generated by `scripts/build_slice.py` and derived from the above.

## Place info (info cards)

- Card text is fetched live from English Wikipedia's REST API when a card opens: CC BY-SA 4.0, credited and linked on every card. Images come from Wikimedia Commons (per-file licences; each card links the file page). Nothing from Wikipedia is stored in this repo except article titles.
- Hand-written fallback blurbs in `data/places.curated.json` are original text (MIT, like the code).
